> 🌐 **官方主页获取**：在浏览器地址栏输入 **土块.art** 进入主页，点击文件下载即可获取本软件。

**第一次使用时，先熟悉这几个基本操作。**

- 双击 `ToolKit.exe` 启动。当前构建要求 Java 21 及以上运行环境；如果提示缺少 Java，需要先补齐运行环境。
- 主界面显示九个功能入口，点击图标进入，点击各功能左上角的“<< 返回菜单”回到主页。
- 拖动窗口空白处可以移动窗口，拖动边缘或四角可以调整大小。
- 多数文件工具通过“拖入文件”开始处理：在文件资源管理器中选中文件，按住鼠标左键拖到指定区域，松开即可。
- 部分点阵画面单击只是播放或停止音乐，不是开始处理按钮。
- 返回菜单通常只是切换界面，**不等于取消正在进行的后台任务**。

软件默认关闭行为是“最小化到系统托盘”。点击右上角关闭按钮后，软件可能仍在运行：

- 双击任务栏右下角的 ToolKit 托盘图标，可以重新显示窗口。
- 右键托盘图标，选择“完全的退出”，才是彻底退出软件。

**找不到某个功能时，可以先调整主页。**

主菜单默认只有九个位置。“粘贴板助手”“大声密谋”“公告比对”“编程助手”等功能，需要从控制中心换到主页。

1. 点击主菜单左上角的齿轮，打开“ToolKit 控制中心”。
2. 进入“主页板块定制”。
3. 将下方“待命板块仓库”中的功能拖到上方九宫格，替换原来的位置。
4. 上方九宫格中的两个功能也可以相互拖动，调整顺序。
5. 不方便拖动时，可以先点击一个功能，再点击目标位置进行交换。
6. 点击“保存设置”。

“恢复默认主页”可以恢复最初的九个功能。

在“外观与常规设置”中，还可以调整关闭行为、选择本地背景图片、改变背景明暗，以及开启或关闭 MITI 小猫。

下面可以按自己的需求选择功能：

| 想做什么 | 使用哪个功能 |
|---|---|
| 统一文件名、批量改名、整理银行回单 | 重命名助手 |
| 检查供应商多轮报价中的异常规律 | 数据校对 |
| 根据文件名寻找文件或文件夹 | 查找助手 |
| 从指定格式的 Word 中提取评分表 | 评分助手 |
| 批量修改文档中的文字 | 内容替换 |
| 压缩或解压 ZIP、解压 RAR | 解压缩助手 |
| 查询行政地区、邮编和地方介绍 | 地区助手 |
| Word、PDF、图片格式转换 | 转换助手 |
| 在电脑、手机之间收发文件 | 传输助手 |
| 保存常用文字，快速复制粘贴 | 粘贴板助手 |
| 将文字加密、伪装，再解密还原 | 大声密谋 |
| 核对 Word 与 PDF 中的公告关键字段 | 公告比对 |
| 编译运行自己的 Java Swing 小工具 | 编程助手 |

**“重命名助手”可以处理普通改名、批量改名和银行回单。**

进入后，点击上方“当前模式”按钮，可以依次切换四种模式。请先选好模式和参数，再拖入文件。

**协同改名助手：手动选择公司，统一命名。**

1. 选择标段、包号和文件类型。
2. 在供应商管理区域填写公司名称，点击“保存公司”，也可以按回车保存。
3. 在公司列表中选中需要使用的公司。
4. 查看右侧名称预览。
5. 将一份或多份文件拖到右侧区域。

文件会在原目录中直接改名，名称形式类似：

```text
标1包1-甲公司-所选文件类型.pdf
```

原扩展名会保留。文件夹会被跳过。

**协同批量改名助手：从原文件名中提取公司名称。**

1. 切换到“协同批量改名助手”。
2. 选择标段、包号和文件类型。
3. 拖入需要处理的文件。

程序从原文件名**最后两个下划线之间**提取公司名称。例如：

```text
原文件：资料_甲公司_报价.pdf
提取公司：甲公司
```

文件名缺少两个下划线时，该文件会被跳过。

普通改名和批量改名都需要注意：

- 修改的是原文件名，不会另外复制一份文件。
- 遇到同名文件，会自动追加 `-复件1`、`-复件2` 等编号。
- 点击“撤销上一步改名”，可以尝试恢复上一批改名操作。
- 文件已经被移动、被其他程序占用或没有权限时，改名或撤销可能失败。

**农业银行、招商银行回单模式：拆分 PDF 并自动命名。**

1. 切换到对应银行模式。
2. 拖入 PDF，或拖入装有 PDF 的文件夹。
3. 等待处理完成。
4. 打开输出文件夹，检查生成的单页回单及名称。

命名形式分别为：

```text
农业银行：收款方账户-收款方户名-交易时间-金额.pdf
招商银行：收款账号-收款人-交易日期-金额.pdf
```

输出位置：

- 拖入单个 PDF：输出到原目录中的“回单重命名-输出”文件夹。
- 拖入文件夹：输出到其同级的“原文件夹名-重命名”文件夹。
- 文件夹只处理直接包含的 PDF，不继续处理子文件夹。
- 多页 PDF 会拆成单页，原 PDF 保留。
- 回单模式不能使用“撤销上一步改名”。

回单通过 PDF 文字识别字段，没有图片 OCR。扫描版或格式不匹配时，可能出现“未获取账号”“未知时间”等名称，需要人工核对。处理过程中不要切换银行模式。

**“数据校对”用于检查同一标包内供应商多轮报价的异常情况。**

它需要符合表头要求的 `.xlsx`，不是随便拖入一张 Excel 就能完整校验。

1. 将待检查数据放到 Excel 的**第一个工作表**。
2. 确认供应商列的表头包含“供应商名称”。
3. 标包列使用“标包编号”。
4. 报价列按实际轮次使用以下名称：

```text
首轮报价
二轮报价
三轮报价
四轮报价
五轮报价
六轮报价
终轮报价
```

5. 点击右上角的精度控制器，选择“精确校对”“保留一位小数”“模糊至个位”或“模糊至十位”。
6. 将 Excel 拖入中央区域，软件自动开始检查。
7. 发现异常时，查看弹出的校验看板。

看板包含预警明细、报价走势图和降幅信息。图表可以拖拽平移、滚轮缩放，鼠标悬停可以查看完整名称。

点击“导出报告与截图”，选择文件夹，可以保存 TXT 分析报告和 PNG 看板截图。

需要注意：

- 一次拖入多个文件时，只检查第一份。
- 调整精度后，需要重新拖入文件检查。
- 缺少“标包编号”时，数据会归入“默认标包”。
- 报价应填写为数值，或能够直接解析的数字文字；带单位、千位逗号的文字可能无法读取。
- 空报价、空供应商，以及供应商名称包含 `※` 的行会被跳过。
- 表头没有被正确识别时，即使没有预警，也不能说明数据已经全部检查。
- 软件不会修改原 Excel。

它主要检查涨价、相同降幅，以及报价中的等差、等比等规律，结果应作为进一步核查的线索。

**“查找助手”根据文件名找文件，不搜索文件正文。**

1. 点击“扫描文件夹”，选择需要查找的目录。
2. 等待目录扫描完成。
3. 根据需要勾选 Word、Excel、PDF、其他，或“仅文件夹”。
4. 在左侧规则框中，每行输入一个关键词，例如：

```text
报价
评审报告
采购公告
```

5. 点击“提取关键项”。

文件名包含任意一行关键词，就会出现在结果中；英文不区分大小写。

结果列表可以查看类型、大小和修改时间，鼠标悬停可以查看完整路径。选中一项或多项后，可以拖到其他接收文件的窗口。

“刷新总览”只是恢复完整列表，**不会重新扫描磁盘**。如果目录中新添了文件，需要重新点击“扫描文件夹”。

另外：

- “提取关键项”只是筛选结果，不会自动复制文件。
- 修改类型筛选后，如仍需关键词结果，应再次点击“提取关键项”。
- 软件会恢复上次的扫描结果，但恢复的列表不一定反映磁盘最新变化。
- 部分系统目录、缓存目录和符号链接会跳过。

**“评分助手”从指定格式的 Word 文档中提取评分表，生成 Excel。**

1. 准备一份 `.docx` 文档。
2. 进入“评分助手”。
3. 将文档拖入中央点阵区域。
4. 等待“读取成功”提示。
5. 到桌面查看生成的 Excel。

它寻找的正文标题包括：

```text
技术评分标准
商务评分标准
技术评审细则
商务评审细则
```

对应标题段落还需要包含 `%` 或“权重”，程序才会继续提取后面的表格。

如果提示“很抱歉，我读取不到”，可以先检查：

- 文件是否为 `.docx`。
- 标题是否使用了以上文字。
- 标题段落是否包含百分比或“权重”。
- 表格是否位于对应标题之后。

这个功能不是通用的 Word 转 Excel。导出时会按程序规则整理表格；例如列数超过三列的表格会省略前三列，部分相同内容会合并单元格，结果需要打开检查。

输出文件名称类似“技术评分标准第一份.xlsx”“商务评分标准第一份.xlsx”。重名时会增加 `_副本1` 等编号，原 Word 不会修改。

一次拖入多个文件时只处理第一份，建议一次拖一份。

**“内容替换”可以批量修改文档文字，也可以同时修改文件和文件夹名称。**

**这个功能会直接覆盖原文件，没有撤销。请先使用副本操作。**

默认前五行对应模板中的固定文字：

```text
XXX项目
NARI-XXXXXX
2026年XX月XX日
XXXXXXXXXXX
****@qq.com
```

右侧填写要替换成的新内容，第六行可以自定义原词和新词。

操作步骤：

1. 填好需要替换的内容。
2. 如果需要自己指定所有原词，点击右上角圆形 **C**，切换为“六行全自定义”。
3. 根据需要设置 **A** 和 **B**。
4. 将单份、多份文件，或整个文件夹拖入下方日志区域。
5. 查看“批量替换确认”提示，确认后开始。
6. 等待日志和完成提示，再检查处理结果。

四个圆形按钮的含义：

| 按钮 | 作用 |
|---|---|
| A | 切换纯黑模式或保留原色；默认纯黑开启 |
| B | 开启或关闭文件、文件夹名称替换；默认关闭 |
| C | 切换固定模板与六行全自定义 |
| D | 清空运行日志，不撤销文件修改 |

这些字母是界面按钮标识，不是键盘快捷键。

格式及处理范围：

- 建议使用 `.docx`、`.pptx`、`.xls`、`.xlsx`。
- 旧 `.doc` 在界面中有明确警告，建议先另存为 `.docx`。
- 没有 PDF、TXT、CSV 的正文替换功能。
- 文件夹会递归处理内部子项。
- Excel 只替换文字单元格，不修改数字和公式单元格。
- 原词和新词都需要非空，不能通过把新词留空来删除文字。
- 匹配区分大小写，使用普通文字替换，不是正则表达式。
- Word、PPT 中命中的段落可能重新合并文字格式，混合字体、颜色等格式需要事后检查。

开启 B 后，名称替换还会作用于其他格式的文件，甚至可能改到扩展名，因此应检查替换词是否过于宽泛。

**“公告比对”核对 Word 和 PDF 中的三个关键字段。**

核对内容为：

- 项目编号。
- 获取截止时间。
- 应答截止时间。

操作步骤：

1. 左侧拖入 Word，支持 `.docx`、`.doc`。
2. 右侧拖入 PDF。
3. 点击“开始比对”。
4. 在日志中查看各字段的提取值、匹配情况和冲突提示。

也可以同时选中一份 Word 和一份 PDF，拖到任意一侧，软件会自动归位。

更换文件时重新拖入即可；双击某一侧区域可以清空该侧文件。“清空记录”会清空两份文件选择和日志。

需要注意：

- 它不是全文逐字比较。
- 不修改两份原文件，也没有自动导出报告功能。
- 扫描 PDF 没有 OCR，可能无法提取文字。
- Word 中位于表格内的关键字段可能无法识别。
- 文档措辞或日期格式不同，也可能导致提取失败。请查看日志里实际提取到的内容，而不只看最后的弹窗。

**“转换助手”负责 Word、PDF 和图片之间的指定格式转换。**

| 拖入文件 | 转换结果 |
|---|---|
| `.doc`、`.docx` | PDF |
| `.pdf` | DOCX |
| `.jpg`、`.jpeg`、`.png`、`.bmp` | PDF |

这个功能需要本机安装完整、可用的 **Microsoft Office Word**，WPS 不能替代这里的 Word 环境。

1. 进入“转换助手”。
2. 等待右上角 Word 图标完成检测。
3. 指示灯蓝色表示可用，黄色表示检测中，灰色表示未检测到可用环境。
4. 选中一份或多份支持格式的文件，拖入中央区域。
5. 等待总进度完成。
6. 到各原文件所在目录查看转换结果。

安装或修复 Word 后，可以点击右上角 Word 图标重新检测。

注意：

- 不支持拖入文件夹。
- 一批文件中只要包含不支持的格式或文件夹，整批不会开始。
- 多张图片会分别生成 PDF，不会合并成一个 PDF。
- 原文件保留，输出文件位于原目录。
- 重名时会追加 `_复件1` 等编号。
- 转换通过本机 Word 完成，不会自动上传到在线转换网站。
- PDF 转 Word 后的排版、表格和图片位置需要检查，复杂文档不一定完全还原。

**“解压缩助手”通过拖放位置区分压缩和解压。**

记住：**左半边解压，右半边压缩。**

解压操作：

1. 如压缩包有密码，先点击右上角“时空怀表”图标。
2. 填写密码，点击“保存设置”。
3. 将一个或多个 ZIP、RAR 压缩包拖到中央区域的左半边。
4. 等待完成。
5. 到压缩包原目录中，打开与压缩包同名的文件夹。

例如：

```text
资料.zip → 同目录下的“资料”文件夹
```

压缩操作：

1. 不需要密码时，先在怀表中“清空密码”；需要密码时先保存密码。
2. 选中需要打包的文件或文件夹，可以多选。
3. 拖到中央区域的右半边。
4. 所选项目会合成一个 ZIP，保存在第一个选中项目所在的文件夹。

默认文件名为 `ToolKit归档文件.zip`。重名时会增加“附件”等编号。

需要注意：

- 同一份怀表密码同时用于解压和新建加密 ZIP。
- 压缩不会删除原文件，也不会覆盖同名 ZIP。
- **解压到已有同名目录时，会覆盖其中同路径、同名的文件，没有再次确认。**
- RAR 解压需要软件配套的 `UnRAR.exe`，缺少组件时应补齐安装文件。
- 一批处理中途失败时，已经解压出的文件可能保留。
- 返回菜单不等于取消解压或压缩任务。

**“地区助手”可以查询行政地区、邮编和地方文化介绍。**

1. 在“输入详细地址”中填写地址，尽量带上省、市、区县。
2. 停止输入约一秒，软件自动查询，无需另点查询按钮。
3. 左侧查看地区和邮编，右侧查看“传统文化与美誉”。
4. 双击某一栏的有效结果，可以复制该栏内容。
5. 点击“横版导出”，保存左侧地区信息。

也支持输入行政区划代码：可以填写 6—12 位数字，程序按前六位查询。这里填写的是行政区划代码，不是邮政编码。

注意：

- 地址查询需要网络。右上角地球仪的 ON/OFF 仅表示网络探测结果。
- 匹配失败时，可以先删去街道、门牌等细节，只输入省、市、区县。
- 邮编显示 `000000` 时，表示程序没有查到邮编，不应直接作为正确邮编使用。
- 右侧文化文字由 AI 生成，适合作为介绍参考。
- “横版导出”只保存左侧地区和邮编，不包含右侧文化介绍。
- 导出为桌面 TXT，同样结果重复导出会覆盖同名 TXT。

**“传输助手”可以让手机或其他电脑通过浏览器收发文件。**

文件仍保存在这台电脑上，因此分享时需要保持电脑和传输服务运行。

电脑向其他设备发文件：

1. 将准备分享的文件或文件夹拖入中间挂载区。
2. 同一局域网内，点击“启动 LAN 直连”。
3. 等待访问地址出现。
4. 点击地址可以复制链接并在电脑浏览器中打开；手机也可以通过“扫码”访问。
5. 在访问页面中点击文件旁的“下载”。

文件夹下载时会自动打包为 ZIP，部分图片、TXT、PDF 可以在网页中预览。

设备不在同一局域网时，可以使用“启动 WAN 穿透”，等待公网地址出现后，再发送链接或二维码。该模式需要网络和软件配套的 SSH 组件。

手机向电脑发文件：

1. 用手机浏览器打开传输页面。
2. 点击网页顶部上传区域，选择文件。
3. 等待上传完成。
4. 在电脑的“下载”目录中打开 `CloudShareUploads` 文件夹查看。

使用时需要知道：

- “访问门禁”中的账号、密码都为空时免登录；需要登录验证时，填写账号和密码。
- 上传同名文件会覆盖上传目录中的原文件。
- 双击电脑端挂载区只清空共享列表，不删除原文件。
- 修改电脑端共享清单后，接收方需要刷新网页。
- 返回菜单不会停止共享。分享结束后，点击“关闭 LAN 直连”或“关闭 WAN 穿透”。
- 完全退出软件后，传输服务停止。

**“粘贴板助手”是九个常用文字存储格。**

它不会自动记录系统中的每一次复制，需要自己把文字放进去。

1. 点击一个格子。
2. 按 `Ctrl + V` 粘贴文字，也可以直接输入。
3. 修改后会自动保存，不需要点击保存。
4. 取用时点击该格，按 `Ctrl + C` 复制。
5. 没有选中文字时复制整格，选中了文字时只复制选中部分。

快捷操作：

| 操作 | 效果 |
|---|---|
| 双击格子 | 放大该格 |
| 再次双击或按 Esc | 恢复九宫格 |
| Alt + 1～9 | 定位并全选对应格子的内容 |
| Ctrl + A 后按 Delete | 清空当前格子 |

按 `Alt + 数字` 后直接输入或粘贴，会替换该格原来的文字。

内容会保存在本机，下次启动恢复。它主要保存文字，不是文件或图片剪贴板，也不应当作密码保险箱。

**“大声密谋”是文字加密与解密工具，不是在线聊天室。**

双方需要使用完全相同的密钥。

发送方：

1. 在顶部“加密密钥”中填写约定好的密钥。
2. 在左侧输入原文。
3. 点击“执行加密”。
4. 双击右侧文本区域，复制整段密文。
5. 使用自己的聊天软件发送密文。

接收方：

1. 将密文粘贴到左侧输入区。
2. 填写完全相同的密钥。
3. 点击“执行解密”。
4. 在右侧查看原文。

密钥可以使用这样的格式：

```text
约定口令#阿巴
```

`#` 后面是用于伪装密文的字符，需要至少包含两个不同的非空白字符。双方需要填写完整密钥，包括 `#` 后的内容。

另外：

- 左侧虽然标成“密文输入”，加密时仍然在这里填写原文。
- 双击左、右文本区，都可以复制该区全部内容。
- 密钥不同或密文损坏时会提示解密失败。
- 该功能不会替你联网发送，也没有自动保存结果的功能。

**“编程助手”可以把 Java Swing 代码变成一个自定义工具。**

这个功能适合有编程基础，或能够核对生成代码的用户。

1. 进入“编程助手”。
2. 点击“获取卷轴”，软件会把编写要求复制到剪贴板。
3. 将这些要求粘贴给 AI，再补充自己想实现的功能。
4. 把得到的完整 Java 源码粘贴回编辑区。
5. 点击“编译并运行”。
6. 成功后进入工具界面；失败时查看下方控制台的错误行号和说明。

代码通常需要：

- 使用一个公开的 Java 类。
- 继承 `javax.swing.JPanel`。
- 提供公开、无参数的构造函数。
- 包含需要的 `import`。

运行后可以点击“修改代码”回到编辑器，“查看当前运行”切回已有工具，“重新加载”重新编译当前代码。

需要注意：

- “获取卷轴”只是复制要求，不会自动调用 AI。
- 当前是一个自定义工具槽位，后一次成功保存会替换之前保存的源码。
- 下次进入模块时，会尝试自动编译和运行已保存代码。
- 需要包含 Java 编译器的 JDK 环境，只有普通运行环境时可能无法编译。
- 代码会真实执行文件、网络等操作，没有独立沙箱。只运行自己理解或可信的代码。

**MITI 小猫可以在主菜单中互动和聊天。**

- 左键点击小猫，可以触发动作或语句。
- 按住左键拖动小猫，松开后会吸附到附近位置。
- 右键点击小猫，打开聊天输入框。
- 输入文字，按回车或点击爪印按钮发送。
- 再次右键点击，可以关闭聊天框。
- 进入功能模块时，小猫会隐藏，回到主菜单后恢复显示。

聊天需要联网，回复会调用配置的 AI 服务。它用于聊天陪伴，文档处理应使用对应工具模块。

不想显示小猫时，打开控制中心，在“外观与常规设置”中取消“启用可恶的小猫？”，再保存。

**“拯救公猪”小游戏从主菜单进入。**

先点击主菜单空白处，再按 **G** 进入游戏；按 **E** 退出游戏并返回软件主页。

游戏菜单包含“故事模式”“排名模式”“全球排行”和“游戏设置”。也可以按数字 1、2、3，分别进入故事模式、排名模式和排行榜。

| 按键 | 作用 |
|---|---|
| 空格或 ↑ | 按提示开始、进行跳跃 |
| → | 向右格挡 |
| ← | 向左格挡 |
| ↓ | 护盾可用时开启护盾 |
| E | 退出小游戏 |

故事模式先播放开场，出现提示后按空格开始。排名模式可以在“游戏设置”中选择简单、普通或硬核难度。

护盾持续约 10 秒，冷却约 30 秒。游戏失败后，可以点击“上传战绩”，填写登榜名称，再到“全球排行”查看；上传和读取排行需要网络。

**遇到问题时，可以先按下面的方法检查。**

| 遇到的情况 | 优先检查 |
|---|---|
| 关闭窗口后还在运行 | 默认是最小化到托盘；右键托盘选择“完全的退出” |
| 主页没有想用的功能 | 打开控制中心，将功能换入九宫格 |
| 拖入文件后没反应 | 是否拖到正确区域、格式是否支持、是否已有任务运行 |
| 文件改名失败 | 文件是否被打开、目录是否有写入权限 |
| 数据校对没有结果 | 是否为 XLSX、数据是否在第一个工作表、表头是否正确 |
| 评分助手读取不到 | 是否为 DOCX、标题和权重写法是否符合要求 |
| PDF 字段提取失败 | 是否为扫描图片版，或文档版式不符合识别规则 |
| 转换助手指示灯灰色 | 是否安装完整 Microsoft Word，点击图标重新检测 |
| 手机打不开传输页面 | 对应服务是否开启、网络是否互通、是否仍使用当前有效链接 |
| 回到主页后任务还在运行 | 返回菜单不是取消任务，共享服务也需要单独关闭 |
| 编程助手提示没有编译器 | 运行环境是否包含 JDK 编译器及 `jdk.compiler` 模块 |

### 📌 V1.9.8 底层稳定性与实用体验重构 (2026/10/29)

1. 后台任务改用虚拟线程：以前随手写 `new Thread().start()`，并发任务一多就容易消耗大量系统资源。这次借升级 Java 21 的契机，全面切换为轻量的虚拟线程，多任务后台跑起来更省内存、更稳当。
2. 根治拖拽死锁，重新开启硬件加速：之前一开 Direct3D 硬件加速软件就偶发卡死，一直误以为是加速代码有 Bug。这次反复排查才发现，真正罪魁祸首是“Windows 底层拖拽”与“输入法状态”在窗口边缘撞车导致的死锁（已在 1.9.7 彻底搞定）。排除了真正病因后，顺理成章重新开启了 Direct3D 加速和 Java 21 ZGC 垃圾回收，长时间挂机不再偶发卡顿。
3. 解决动画偶发掉帧（锁定 1ms 系统时钟）：Windows 默认的时钟调度精度很粗糙（约 15.6ms），导致软件里的平滑动画像素偶尔会“大跨步跳帧”，看着一卡一顿。通过调用底层多媒体 API 把时钟精度锁定在 1ms，并挂了个低功耗后台线程防止 Windows 省电时自动把精度调低，退出时再干净复原。所有动画终于能稳稳保持 60 帧丝滑。
4. 清理商用许可证风险库：彻底移除有商业限制的 `itextpdf`，改用完全开源合规的 `Apache PDFBox`；淘汰了一大批废弃的旧版 Java API，把依赖库统统升级到安全稳定的现代版本。
5. 规整 HTTPS 网络请求：规范了调用高德和民政局接口时的连接逻辑，老老实实走系统受信任证书验证，避免公共网络下出现证书错误或安全隐患。
6. 主页九宫格支持自由定制：大家高频用的功能不一样，现在在系统设置里可以自己把常用的 9 个板块拖到首页排布。
7. 去掉多余的悬停气泡：很多用户反馈鼠标划过去到处弹提示框很晃眼，移除了大部分不必要的浮动提示，托盘提示也精简为“ToolKit”。
8. 新增「粘贴板助手」：平时复制粘贴高频文字经常需要临时存一下，专门做了这个小工具，支持保存常用文本与 Emoji 表情。
9. 修复替换助手“关机失忆”：之前全自定义模式下辛苦敲的前 5 行替换内容以及模式按钮，关掉软件就被清空了。这次加上了即时存盘，重启后内容老老实实都在。
10. 极速云传（手机传电脑）优化：以前手机传文件老是因为系统安全权限被拦下，这次把接收路径改到通用的“下载”文件夹，不需要管理员权限也能用；局域网和外网穿透端口明确分开；重新做好了手机网页端的触屏适配。
11. 转换助手减负提速：去掉了右上角无谓的呼吸动效，把精力放在实用上；本地 Office 安装路径只在初次使用时探测一次并记住，不用每次转换都慢吞吞重新扫盘。
