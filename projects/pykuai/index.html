>> PYPI RELEASE (v1.2.7) << >> GITHUB SOURCE <<

[01] Micro-Kernel Core

Drop any three-lowercase-letter module (^[a-z]{3}$) subclassing BaseEngine into pykuai/engines/. Auto-wired into the tray, CLI router, and dependency scanner with zero boilerplate.

[02] 2-Letter Ergonomics

Navigate with six doubled commands inside the REPL: tt (Tool Tray), pp (Pull Packages), vv, cc, hh, and gg — or run any tool headlessly via pykuai tt .

[03] Cyber-Dark TUI

Mouse-clickable Rich & Textual studios with ? / F1 help modals, drag-and-drop image auto-routing, pixel-snake launch intro (--fast to skip), and toggleable CC0 arcade SFX.

[04] Engine :: ifc

Image Format Converter supporting ICO, PNG, JPG, WEBP, AVIF, GIF, BMP, and TIFF — EXIF auto-orient, atomic temp writes, quality presets, and 8..256px multi-res .ico packing.

[05] Engine :: ytd

Media downloader powered by yt-dlp + FFmpeg: best/1080p/mp3/m4a profiles, bilingual --subs, isolated --login YouTube auth to ~/.pykuai/cookies.txt, and verified --install-ffmpeg.

[06] Lean PyPI Runtime

Ships cleanly on PyPI with zero 200+ MiB FFmpeg bloat. External tools resolve from system PATH or download SHA256-verified on demand into ~/.pykuai/tools/.
