* **文件记忆**：在“我的文档”中的“黑洞入口”文件夹下，默认隐藏了 3 个记忆配置与数据文件。如果您开启了“查看隐藏文件”，**请切记不要删除它们**，它们记录了您的所有设置偏好、待办事项和快捷网址。

### 🖱️ 核心交互：左右键与鼠标功能大全（必读）

为了保持界面的绝对极简（无边框、无按钮），黑洞的所有交互都深度绑定了鼠标操作：

* **对于“黑洞”悬浮球本身**：
* **左键按住拖拽**：在屏幕上自由移动黑洞。
* **左键双击**：立刻触发“系统冗余吞噬”（快速清理内存）。
* **右键单击**：呼出**核心控制面板**（暗物质交互菜单），进行添加待办、查看近期吞噬、打开网页等操作。


* **对于“暗物质交互菜单”中的列表**：
* **待办事项（未完成）**：**左键**点击 = 核销完成并播放吞噬动画；**右键**点击 = 直接粉碎删除。
* **历史待办（已完成）**：**左键**点击 = 弹出独立视窗查看完整情报；**右键**点击 = 抹除历史痕迹。
* **近期吞噬（文件记录）**：**左键**点击 = 直接打开该文件；**右键**点击 = 打开文件夹并自动定位高亮该文件。


* **对于“屏幕便利贴”（截图贴图）**：
* **左键按住拖拽**：在屏幕上自由移动便利贴。
* **右键单击**：呼出控制面板（可选择复制图像、另存为本地文件、关闭销毁）。
* **鼠标滚轮**：向上滚动放大便利贴，向下滚动缩小便利贴。

### 🛠️ 6 大核心功能详解

#### 1. 拖入自动归档 (Auto-Archiving)

* **设计初衷**：在日常招标业务中，桌面常常堆满复杂的文档。为了解决桌面杂乱问题，软件借鉴了检索助手及诸多监听灵感开发此功能。
* **使用方法**：将暂时不用又不能删除的单个文件或整个文件夹，直接按住鼠标左键拖入“黑洞”中。
* **归类逻辑**：软件会自动将其归纳并转移至您的“我的文档/黑洞入口”目录下的 **9 个分类文件夹**之一（注：“不明物质”分类通常用不到，作为其他无法识别后缀的杂项兜底）。
* **⚠️ 安全机制（v1.1.0 新增）**：
* **防误吞保护**：如果您拖入的文件**正在被其他程序打开/占用**（如 WPS 正在编辑的 Excel），黑洞会自动静默跳过，绝不会导致文件损坏或丢失。
* **重名保护**：如果黑洞内已存在同名文件，黑洞将拒绝吞噬并保留原文件，防止重要数据被意外覆盖。



#### 2. 快捷网络功能 (Quick Web Links)

* **功能说明**：类似于浏览器的书签标签页，但无需手动打开浏览器，右键点击黑洞即可在“快捷网络”中快速访问。
* **使用方法**：在菜单中点击“添加地址”，先输入名称，再输入网址即可保存。点击后软件会自动启动您的默认浏览器并跳转。
* **底层存储**：数据会保存在隐藏的 `bookmarks.txt` 文件中，您也可以在菜单中点击“编辑配置”手动修改文本（格式为：`名称|网址`，逐行排列）。

#### 3. 待办事项 (To-Do List)

* **功能说明**：专为日常办公（如下周开标表等工作）设计的轻量级待办提醒。
* **提醒机制**：右键点击黑洞选择“注入待办事项”，设定好时间。当超过设定时间后，黑洞的平时闲置状态会变成**红色的警告环绕图形**进行视觉提醒。
* **操作交互**：在弹出的菜单列表中，**左键**选中代表**完成**，**右键**代表**彻底删除**。托盘菜单的“历史待办”中也支持左键查看详情、右键删除。

#### 4. 快捷区域截图与贴图 (Screenshot & Pinning)

* **快捷键**：
* `Ctrl + Alt + Q`：一键锁定屏幕，进行纯净区域截图。
* `Enter`（回车键）：将选中的截图直接以无损 PNG 格式保存到桌面。
* `Ctrl + T`：**将截图变成便利贴直接置顶悬浮在桌面上**。方便您同时对比查看两个内容，是非常实用的办公辅助功能（支持滚轮缩放大小和右键菜单操作）。



#### 5. 快速清理内存 (Memory Cleaner)

* **功能说明**：针对日常办公中经常遇到的软件卡死、多开导致系统崩溃必须重启电脑的情况提供监控与一键清理。
* **使用方法**：只需**双击两下黑洞**，或者在系统托盘右键选择“系统健康看板 -> 吞噬系统冗余”，黑洞将强制遍历并榨干所有后台驻留进程的空闲内存。

#### 6. 从网页或文档吸收文字与图片 (Drag-and-Drop Capture)

* **文字抓取**：在任何文档或网页中用鼠标选中一段文字，直接拖入黑洞，软件会自动将其在“003_日常文档”中生成并保存为 `.md` (Markdown 闪念笔记) 格式，可以用记事本随时打开。
* **图片抓取**：将网页图片（包括 Base64 格式的图片）直接拖入黑洞，软件会自动解析并保存在“006_图片素材”文件夹中。

### ⚙️ 快捷键与个性化细节

* **边缘自动隐藏**：您可以将黑洞窗口拖拽到屏幕的**上、左、右边缘**，松手后它会自动贴边隐藏收缩，鼠标移入时自动滑出。
* **完全隐藏/显示**：使用系统级全局快捷键 `Ctrl + Alt + E` 可实现软件界面的隐身与随时唤醒。
* **自定义设置**：系统托盘右键菜单支持自由调节黑洞的**视界半径（大小限制在80-200）**、**整体透明度（20%-100%）**以及一键开启/关闭**开机自启**。

### 🚀 v1.1.0 更新日志 (Update Log)

* **✨ 修复了最严重的致命 Bug：** 彻底重写底层拖拽逻辑。现在拖入**已经打开且被系统占用的文件**时，黑洞会触发“无感跳过”防御机制，**不再会导致文件崩溃或永久丢失**。
* **✨ 修复了重名覆盖 Bug：** 当拖入的文件与黑洞内现有文件重名时，系统会强制拒绝吞噬，保护桌面原文件不被误删。
* **🛡️ 修复了底层撕裂闪退 Bug：** 完善了应用的优雅退出机制（Graceful Teardown）。修复了在关闭软件或退出时，因动画高频渲染与底层 C++ 对象销毁冲突导致的 `RuntimeError/KeyboardInterrupt` 报错。
* **🎨 优化了动画反馈：** 解绑了动作动画与文件流的强依赖。现在无论是遇到报错跳过还是成功吞入，黑洞在接受投喂时都会展示流畅完整的“狂暴吞噬”动画。
* **📐 增加了尺寸安全锁：** 防止用户误将黑洞尺寸设置过小导致无法点击操作，现已强制锁定尺寸调节下限为 80。

### 🛑 当前已知 Bug 与风险警示

1. 偶尔会出现全局快捷键（如截图、隐藏）被其他高权限软件拦截而失效的情况，需重新启动软件恢复。
2. 极端多线程拖拽或连续超大文件传输时，交互动画可能会出现短暂的卡顿掉帧。
3. 软件打包为独立 `.exe` 时，可能会偶发部分系统环境依赖丢失的情况。
4. 部分异常物质（无后缀的特殊系统缓存文件）拖入时，可能会触发不可预见的分类错误，已暂时划分至“009_不明物质”进行隔离。
