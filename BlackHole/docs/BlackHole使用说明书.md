### 🖱️ 核心交互：左右键与鼠标功能大全（必读）

为了保持界面的绝对极简（无边框、无按钮），黑洞的所有交互都深度绑定了鼠标操作：

* **对于“黑洞”悬浮球本身**：
* **左键按住拖拽**：在屏幕上自由移动黑洞。
* **左键双击**：立刻触发“系统冗余吞噬”（快速清理内存）。
* **右键单击**：呼出**核心控制面板**（暗物质交互菜单），进行添加待办、查看近期吞噬、打开网页等操作。


* **对于“暗物质交互菜单”中的列表**：
* **待办事项（未完成）**：**左键**点击 = 核销完成并播放吞噬动画；**右键**点击 = 直接粉碎删除。
* **历史待办（已完成）**：**左键**点击 = 弹出独立视窗查看完整情报；**右键**点击 = 抹除历史痕迹。
* **近期吞噬（文件记录）**：**左键**点击 = 直接打开该文件；**右键**点击 = 打开文件夹并自动定位高亮该文件。


* **对于“屏幕便利贴”（截图贴图）**：
* **左键按住拖拽**：在屏幕上自由移动便利贴。
* **右键单击**：呼出控制面板（可选择复制图像、另存为本地文件、关闭销毁）。
* **鼠标滚轮**：向上滚动放大便利贴，向下滚动缩小便利贴。

### 🛠️ 7 大核心功能详解

#### 1. 拖入自动归档 (Auto-Archiving)

* **设计初衷**：在日常招标业务中，桌面常常堆满复杂的文档。为了解决桌面杂乱问题，软件借鉴了检索助手及诸多监听灵感开发此功能。
* **使用方法**：将暂时不用又不能删除的单个文件或整个文件夹，直接按住鼠标左键拖入“黑洞”中。**（v1.2.0 现已支持精准的圆形视界判定，拖入透明四角区域不会引发误触）**。
* **归类逻辑**：软件会自动将其归纳并转移至您的“我的文档/黑洞入口”目录下的 **9 个分类文件夹**之一。
* **⚠️ 安全机制（v1.2.0 重大升级）**：
* **防误吞视觉欺骗**：如果您拖入的文件**正在被其他程序占用**，黑洞在底层会静默跳过不破坏原文件，但在表层仍会**完整播放吞噬动画与粒子碎裂特效**，提供完美的交互闭环。
* **秒级重名保护**：拖入同名文件时，系统会在保留原文件的基础上，为新文件追加精确到秒的独立时间戳（如 `文件名_20260910_143005.后缀`），即使一分钟内拖入多个同名文件也绝不冲突。



#### 2. 像素级解体特效 (Particle Burst Engine) *[v1.2.0 全新功能]*

* **功能说明**：为您提供极其解压的极客级视觉反馈。
* **触发机制**：文件被拖入黑洞瞬间，系统会抓取其真实系统图标，打碎成数十个带有物理重力与切线属性的像素粒子。
* **视觉表现**：借助独立的 800x800 穿透图层，粒子能突破传统软件的矩形限制，在屏幕上自由飞溅并呈螺旋状卷入黑洞奇点。支持最多 5 个文件的**混合色彩爆裂**。

#### 3. 快捷网络功能 (Quick Web Links)

* **功能说明**：类似于浏览器的书签标签页，无需手动打开浏览器，右键点击黑洞即可快速访问。
* **使用方法**：在菜单中点击“添加地址”，输入名称与网址即可保存。数据隐秘存储于 `bookmarks.txt` 中。

#### 4. 待办事项 (To-Do List)

* **功能说明**：专为日常办公（如下周开标表等工作）设计的轻量级待办提醒。
* **提醒机制**：右键点击黑洞选择“注入待办事项”并设定时间。超时后，黑洞将转变为**红色的警告环绕图形**进行高能视觉提醒。

#### 5. 快捷区域截图与贴图 (Screenshot & Pinning)

* **快捷键**：
* `Ctrl + Alt + Q`：一键锁定屏幕，进行纯净区域截图。
* `Enter`：将截图无损保存至桌面。
* `Ctrl + T`：**将截图化作便利贴置顶悬浮在桌面上**，支持滚轮缩放，是比对繁杂数据时的绝佳辅助。



#### 6. 快速清理内存 (Memory Cleaner)

* **功能说明**：一键解决办公中软件卡死、多开导致的系统负荷问题。
* **使用方法**：**双击两下黑洞**，系统将强制榨干所有后台驻留进程的空闲内存。

#### 7. 从网页或文档吸收文字与图片 (Drag-and-Drop Capture)

* **文字抓取**：将选中的文字拖入黑洞，自动在“003_日常文档”中生成 `.md` 闪念笔记。
* **图片抓取**：将网页图片拖入黑洞，自动解析保存至“006_图片素材”。

### 🛑 当前已知 Bug 与风险警示

1. 偶尔会出现全局快捷键（如截图、隐藏）被其他高权限软件拦截而失效的情况，需重新启动软件恢复。
2. 极端多线程拖拽或连续超大文件传输时，交互动画可能会出现短暂的卡顿掉帧。
3. 软件打包为独立 `.exe` 时，可能会偶发部分系统环境依赖丢失的情况。
4. 部分异常物质（无后缀的特殊系统缓存文件）拖入时，可能会触发不可预见的分类错误，已暂时划分至“009_不明物质”进行隔离。
